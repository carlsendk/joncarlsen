## Context

DFDS runs distinct businesses in freight, logistics, and the wider group, and
each needed a corporate web presence that the business could keep current. The
customer-experience teams owned the platform underneath, so the job was to build
those sites on the same responsive web foundation rather than as one-off
projects.

## What I did

I was responsible for the software development behind the new corporate websites
for the freight, logistics, and group businesses on dfds.com. We built them on
the responsive web platform the department had established, so the sites were
mobile-ready from the start and shared the same delivery and content practices as
the rest of the customer-facing web. That kept the businesses on one consistent
platform instead of separate stacks that each needed their own care.

## Outcome

The freight, logistics, and group businesses gained modern corporate websites on
a shared, mobile-ready platform, built and released with the same practices as
the rest of DFDS's web. Putting them on one foundation made each site cheaper to
run and faster to change than a bespoke build would have been.
