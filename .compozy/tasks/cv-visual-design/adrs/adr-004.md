# ADR-004: CSS-only faint film-grain texture (no image assets)

## Status

Accepted

## Date

2026-06-09

## Context

The PRD lists "subtle texture & depth" as a core feature but also flags that
texture must never reduce text contrast, and the perf budget discourages extra
image requests. The owner chose faint film grain over an accent-tinted mesh glow.

## Decision

Render the grain as a **CSS-only overlay**: an inline SVG `feTurbulence` noise
encoded as a `data:` URI, applied at very low opacity (~3-5%) as a fixed,
`pointer-events: none` layer behind content. No raster image asset, no extra HTTP
request. Because it is a neutral luminance-noise overlay at low opacity, it does
not shift text/background contrast; AA is preserved in both themes. Grain is
applied site-wide; sections keep their solid token backgrounds beneath it.

## Alternatives Considered

### Alternative 1: Accent-tinted mesh/radial gradient glow

- **Pros**: more "designed", adds a cobalt color field behind the hero.
- **Cons**: tints the background — more contrast risk; reads less restrained.
- **Why rejected**: the owner chose grain; grain is the lower-contrast-risk option.

### Alternative 2: A raster noise PNG/texture image

- **Pros**: pixel-exact control.
- **Cons**: an extra image request against the perf budget; another asset to ship.
- **Why rejected**: an inline SVG data URI achieves the same with zero requests.

## Consequences

### Positive

- Tactile depth with zero added network cost and no contrast penalty.

### Negative

- A large-ish data URI string lives in the CSS (kept small via low SVG complexity).

### Risks

- Over-opacity could harm contrast or read noisy — cap opacity low and verify AA
  over the grain in both themes.
