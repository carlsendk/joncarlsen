# ADR-001: "Editorial refined" visual direction via a full disciplined refresh

## Status

Accepted

## Date

2026-06-09

## Context

The CV site is technically strong (one-page Astro + Tailwind, Lighthouse ~100,
near-zero JS, live on joncarlsen.dk) but visually conservative — clean slate/white
minimal. The owner wants it to read as "really cool, professional" for a senior
engineering-leadership job hunt: recruiters scan ~30s, mostly on mobile, and form
a seniority/taste impression fast. Market research shows that for this audience
"cool + professional" comes from restraint executed precisely, not added effects;
heavy motion, 3D, gamification, and low-contrast trendiness actively hurt
credibility.

## Decision

Adopt an **editorial-refined** visual language and apply it as a **single
cohesive pass across all four sections**: an editorial type system (display
headlines + monospace for metadata/dates/labels) with large confident type, a
**single disciplined cobalt-blue accent**, subtle background grain/texture,
**light + dark themes** (system default + manual toggle, soft grays not pure
black), and **quiet micro-interactions** (reveal-on-scroll, hover states,
animated underlines) that fully honor `prefers-reduced-motion`. Type-led, **no
photo** this round. Preserve the single-page shape, near-zero-JS posture, and the
existing performance/accessibility budgets.

## Alternatives Considered

### Alternative 1: Hero-led statement only, lighter elsewhere

- **Pros**: faster, lower risk, concentrates effort on the first impression.
- **Cons**: inconsistent feel between the hero and the rest; the "cool" doesn't
  carry through the scan.
- **Why rejected**: cohesion across the whole page is what reads as considered/
  senior; a half-redesigned page undercuts the goal.

### Alternative 2: Maximal — editorial + bento grid + expressive motion

- **Pros**: most visually striking and memorable.
- **Cons**: more build and perf/JS cost; drifts toward the "modern tech" look and
  risks the gimmicky/over-animated impression that hurts a leadership audience.
- **Why rejected**: exceeds the disciplined-restraint principle; bento and richer
  motion are deferred to a later phase if wanted.

### Alternative 3: Other directions (modern-tech bento, bold minimalist)

- **Why rejected**: the owner chose the editorial/refined direction as the best
  fit for a premium, senior, credible impression.

## Consequences

### Positive

- Premium, considered, distinctly senior impression that still scans in seconds.
- Cohesive across all sections; one design system to maintain.
- Keeps the site's speed and accessibility strengths (a credibility signal itself).

### Negative

- Web fonts (display + mono) add load cost that must be budgeted (subset/preload).
- The theme toggle introduces a small amount of JS (the only client JS).
- More design effort up front than a hero-only touch-up.

### Risks

- Texture/accent could reduce text contrast — must hold WCAG AA in both themes.
- Over-polish could read gimmicky — mitigated by restraint and a senior-tone review.
- Dark-mode flash / contrast pitfalls — soft grays, prevent theme flash, AA both modes.

## Amendment (2026-06-10): one body-prose size (text-base / 16px)

**What changed.** All body prose renders at a single size: `text-base` (16px),
Hanken Grotesk. The earlier `text-lg` (18px) "lead" tier on the hero valueProp,
the Scope line, the Summary paragraph, the Approach narrative, and the /impact +
/work page intros is removed; those blocks now match the body size used by
Credentials, role descriptions, bullets, certifications, and every other section.

**Why.** The editorial direction fixed the three font *families* (ADR-002) but
never specified a numeric size *scale*, so body prose drifted into two sizes
(18px lead vs 16px body). Reading as one document, "similar" prose blocks at
different sizes read as inconsistent. Credentials' 16px is the reference body size.

**Resulting type scale (the documented spec).**
- Display title (h1): Fraunces, text-5xl/6xl.
- Entry title (roles, cards, education, voluntary — h3): Fraunces, text-xl (20px).
- Impact metric: Fraunces, text-2xl/3xl.
- Section label (h2 eyebrow): JetBrains Mono, text-xs (12px), uppercase, tracking-[0.2em].
- Meta (dates, role/period, eyebrows): JetBrains Mono, text-xs (12px).
- Body prose (all paragraphs, bullets, list items): Hanken Grotesk, text-base (16px), leading-relaxed.
- Sub-detail lists (e.g. Education activities): text-sm (14px) — the one tier below body.
